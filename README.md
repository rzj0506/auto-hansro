# ro.hans幸存者助手

基于用户提供的 **v1.3.0** 开发，当前版本 **v1.14.4**，适用于 <https://ro.hans-webgametw.com/>。

[安装／更新脚本](https://raw.githubusercontent.com/rzj0506/auto-hansro/userscript-release/ro-survivors-helper.user.js) · [更新元数据](https://raw.githubusercontent.com/rzj0506/auto-hansro/userscript-release/ro-survivors-helper.meta.js)

使用 Tampermonkey 安装后刷新游戏。首次使用保持暂停，按 F9 展开面板，按 F8 启动／暂停。安装改名后的脚本时，请停用原来的“RO 倖存者：三系法術與寶箱助手”，避免两个版本同时运行。

## 游戏新版本提示

在“走位、拾取與運行設定”里的“遊戲「新版本」提示”选择手动、自动点「稍後」或自动点「重新整理」。默认手动。两个自动选项使用游戏原生按钮，助手暂停时也适用。为避免连续刷新，同一分页面在自动刷新后两分钟内再次遇到提示会交还手动处理。

## 分等级拾取与尾王收尾

在“走位、拾取與運行設定”分别设置两个门槛。宝箱五栏总等级达标后停止主动寻宝，局内角色等级达标后停止主动走向经验宝石。宝箱首张算 1 级，空栏算 0。两个门槛默认都是 0，分别关闭。单人远征中，低于门槛时使用正常寻宝和安全拾取，达标后可用磁铁吸取对应掉落。

尾王击倒后，面板显示原生拾取倒计时。助手会优先拾取磁铁、装备、卡片和宠物蛋，并恢复主动拾取经验。倒数期间按游戏规则结算，原生会锁定宝箱开启。

## 选牌设置、磁铁倒计时与死亡邮件汇总

在“新版技能／寶箱保存與開啟”分别设置技能牌和宝箱。可选全程手动、只自动选已开启的牌，或自动开启并选牌。自动避怪、自动寻宝、安全拾取都位于“走位、拾取與運行設定”。自动寻宝只控制是否走向地面宝箱。

配置磁铁间隔后，面板顶部显示局内剩余秒数、到期等待或引导拾取状态，以及本局已拾取次数。

死亡通知默认从首笔开始累计 30 分钟后统一寄一封摘要，使用原有 EmailJS 模板即可。可调整间隔或填 0 恢复即时报送。保持游戏分页面开启，刷新同一页可继续累计。

## 第二章远征、磁铁与折叠面板

在“自動遠征／新周目開荒”的地图下拉框选择章节内的地图，再选择该章的周目。第二章新增吉芬地下迷宫、时计塔地下、深渊之湖、克雷斯特汉姆修道院和尼芙菲姆原野。固定刷图与首通开荒都会在原生队长界面切到对应章节和周目，沿用游戏的解锁要求。

在“走位、拾取與運行設定”填写“優先拾取磁鐵間隔”，例如 30。需要开启助手和“安全拾取掉落物”。单人远征中按局内时间计算，到点后搜索全图，优先走向可安全接近的地面磁铁。面板会显示磁铁距离、路线危险或不可达，实际拾取后重新计时。填 0 使用原有拾取优先级，默认值为 0。

“職業配置與技能順序”可一次收起职业选择和全部技能栏。重抽、保存、宝箱优先级和其他设置按区折叠，展开面板时可直接看到运行状态与磁铁倒计时。

## 重复远征与新版保存适配修正

v1.13.2 修复到队长身边、出现“和船長說話 空白鍵”仍继续移动的问题：NPC名牌是“遠征隊長”，实际交谈提示却使用“船長”，旧版仅匹配“隊長”而漏掉提示。现在统一兼容船长／队长及游戏四种语言的提示，读取副本清单按钮也使用同一识别规则。

出现目标NPC的原生交谈提示后立即释放移动键，按一次空白键并释放，通过游戏原生输入处理交谈；若700毫秒后仍未切换界面，补点一次原生交谈按钮。不会持续发送空格或点击，其他NPC提示、打开的弹窗、暂停及手动接管时不触发自动交谈。验证包含截图原文、实际客户端四种翻译、空格被拦截后的备用点击和重复远征流程；尚未真实账号实战验证。

v1.13.1 针对角色在队长附近反复移动，移除了v1.13.0的名牌偏移探测。现在只读观察原生3D场景的角色坐标、队长／商人实际坐标和镜头方向：可安全点击时通过游戏原生地面点按触发寻路；不可点击或场景拥挤时按实际世界方向短按移动，近距离缩短按键时长。只认原生交谈提示或原生寻路自动交谈，不把名牌接近当成到达，也不修改角色位置或跳过副本条件。

读不到原生坐标、场景已销毁或画面坐标过期时停止猜测移动并提示等待，暂停和手动接管仍会释放按键。日志显示实际距离，诊断的town部分提供场景连接状态、角色／NPC坐标、镜头方向和坐标更新时间。回归使用当前客户端的原生输入、移动、交谈和点击寻路代码逐帧验证，覆盖多种镜头角度及错误名牌位置；尚未真实账号实战验证。

同时修正新版保存系统处于ES模块局部作用域、无法通过全局变量访问导致一直“等待初始化”的问题。现在通过原生保存复选框、开启按钮和分页面板事件操作，观察原生实际牌面及重抽返回值，不试抽、不多推进随机数。保存再开和整组重绘仍保留原组重抽预算。

## 宝箱“栏位未识别”修复

v1.12.1 修复了出现“靈藥”牌时停在宝箱界面的问题：旧版仅匹配“秘藥”，与游戏当前类型翻译不同。现在优先使用当前原生牌组的真实类型和物品 ID，牌面数量不匹配或原生数据不可用时，使用物品表和类型别名识别；同时兼容“靈藥／秘藥”及中、英、西、葡类型名称。

旧的名称优先级继续生效，例如旧配置“持續傷害秘藥”仍能匹配当前“持續傷害藥劑”，无需重新填写优先级。未确认的类型仍等待手动处理，日志和诊断会列出具体牌名、类型文字及识别来源。选牌、重抽上限、保存模式和神格规则保持原设置。

## 新版技能牌／宝箱：分别保存和开启

已适配 2026-11-18 更新的原生保存系统（公开客户端 `main-BNOcv2PN.hzb98c6b70.js`）。游戏已移除旧“不再翻牌”功能，改为分别保存技能升级机会和宝箱，之后可拿出选牌。保存技能不丢弃升级机会，等级能力与升级回血仍按游戏规则发放；宝箱在拾取保存时付钱，开启保存箱时不重复付费。

在助手的 **“新版技能／宝箱保存与开启”** 中设置：

- **游戏：保存升级选卡／保存宝箱**：两个独立勾选，和游戏暂停菜单的开关同步，使用游戏自己的全局保存偏好。
- **技能牌／宝箱处理方式**随职业配置保存。默认只自动选已开启的牌。可分别改为全程手动，或自动开启并选牌。
- **立即开技能牌／立即开宝箱**：先打开所选类型；助手运行时沿用其优先级、重抽及神格设置，并限制这一轮的自动选择范围。助手暂停时也可用按钮手动打开，后续由原生流程与玩家操作。
- **继续保存目前牌**：保留当前这一组牌，暂缓本局自动取出；原生“继续保存”按钮也有同样的让出效果。按面板开启按钮、原生 HUD 的“开启”、B 键或调整自动范围后恢复，下一局重新开始。

原生连选可能自动转到另一种牌面，只选一种的自动批次会把另一种继续保存，不替你选掉它。手动点原生技能／宝箱分页面板可接管批次，正常处理当前手动打开的类型；手动打开的牌按该类的处理方式决定是否自动选牌。找不到原生接口、当前是旧局、死亡、暂停、收尾结算或非支持模式时不擅自开牌。

重抽计数按每组原生牌面保存：同箱重绘、保存再开启、技能／宝箱互切和重新识别不会清零；连续开启多个保存箱时，每个新箱重新计数。只读取原生牌面和可抽池，不通过试抽判断机会；实际开启和重抽使用游戏原生入口。

自动取出适用于普通单人远征，组队、剧情、爬塔、PVP 和录像不使用此入口。原有已打开牌面的选择逻辑继续保留。到尾王结算时，未使用的保存牌／宝箱按游戏原生规则清理，助手不补发或伪造奖励。验证使用新版原生保存客户端及选择流程的自动化回归，尚未真实账号实战验证。

## 指定神格覆盖与选后放逐

在“五栏位宝箱优先级”中新增两项独立开关，默认关闭，随职业配置保存、导入和导出。

- **指定神格出现时优先覆盖**：勾选后在下方名单填写指定神格，例如 `火箭術 神格 [firebolt]`，也可从神格表选择加入。当牌面出现指定神格时，它优先于原有五栏第一优先级，可替换已有的第一优先级神格，并自动完成原生替换确认。只在已出现且游戏允许替换时选择，不为了指定名单额外重抽。
- **本局选过的神格再次出现时自动放逐宝箱牌**：名单留空时作用于所有职业／技能神格，例如火箭术、冰箭术；也可填写指定名单，限定放逐对象，或明确加入普通神格。首次出现时不会放逐，只有从本局实际持有状态确认已取得后，再次出现才点击原生放逐按钮。手动选取的神格也能识别。

覆盖名单每行一个优先级，同一行用 `|` 并列；选定后不会自动回换同级或较低优先级的其他神格，更高优先级的指定神格仍可覆盖。**覆盖会失去原神格的累计等级及效果**，新神格按游戏原生结果生效；放逐仅阻止该神格之后出现在本局宝箱，不移除当前持有的神格及其当前效果，不放逐对应技能的升级牌。已有神格本身不在配置的覆盖名单时，继续沿用原宝箱设置。

例如：宝箱第一优先级设为思考神格，覆盖名单设为火箭术神格，开启覆盖和选后放逐。前期可按原配置选思考神格；火箭术神格出现时替换它，之后火箭术神格升级再次出现时放逐该宝箱牌，保留当前火箭术神格，继续为其他四栏选牌。

宝箱放逐与技能放逐共用游戏的放逐次数，仍需有可用按钮和剩余次数，不消耗单张／整组重抽，也不计入每箱重抽上限。没有可用放逐时按原选牌及用尽设置处理；助手暂停或自动宝箱关闭时不执行。关闭这两项可恢复旧行为。

本局已取得记录不进入职业配置；同箱重绘、重新识别及局中换神格不会清空，开始新一局重新记录。刷新页面后可重新识别当前持有的神格，刷新前已被覆盖的历史神格不作猜测。使用原生可抽池和按钮，未真实账号实战验证。

## 单人远征死亡邮件提醒（EmailJS）

新增可勾选的死亡邮件提醒，默认关闭，**独立于助手启动开关**；暂停自动操作后，只要游戏页面还在运行，也能检测并发送提醒。

先按 [EmailJS 配置说明](https://github.com/rzj0506/auto-hansro/blob/main/docs/emailjs-setup.md) 连接自己的发信服务、建立模板，再在面板填写收件邮箱、Service ID、Template ID、Public Key。模板的 To Email 填 `{{to_email}}`，Subject 填 `{{title}}`，正文放 `{{message}}`。点击“保存通知设置”和“发送测试邮件”，确认实际收到后再勾选死亡提醒。可直接复制 [HTML 模板](https://github.com/rzj0506/auto-hansro/blob/main/docs/emailjs-template.html)。无需邮箱密码或 Private Key。

每局单人远征的实际死亡只记录一次。正常通关、定时退图、组队、剧情、PVP、爬塔及录像不计入。邮件包含职业、副本、周目、局内存活时间、等级、击杀数与发生时间。自动重开后，上一局已排队的通知仍保留。

发信使用 [EmailJS 官方 REST 接口](https://www.emailjs.com/docs/rest-api/send/)，不添加浏览器扩展权限，不改动游戏时钟。请求串行且至少间隔1.1秒，15秒超时；失败或发送结果不确定时显示原因，不自动重发同一局，也不阻塞其他自动功能。面板显示“EmailJS 已接受”表示接口已接受请求，实际投递需要检查收件箱及服务记录。

通知邮箱和服务参数保存在本浏览器的独立设置中，不进入职业档案、通用配置导出、诊断或 GitHub 文件；换设备需重新填写。“清空通知设置”会删除本机参数并关闭提醒。网页关闭、浏览器冻结和电脑休眠时无法持续检测。此次验证使用模拟邮件接口，未向真实邮箱发送测试邮件；使用前需完成自己的通道测试。

## 基础职业的技能／宝箱配置

“職業配置與技能順序”可以直接编辑九个基础职业。进入副本后自动使用当前角色的基础职业档案，同一职业系的一转、二转、三转共用技能与宝箱配置。

每份档案独立保存：五个技能位置、4／5 技数量、技能选牌与稀有度偏好、放逐及排除名单、角色等级／宝箱总等级规则、保存牌自动开启范围、宝箱五栏并列优先级、指定神格覆盖与选后放逐、智能补齐、两种重抽开关、方式、上限、保留次数和用尽处理。前 3 个技能现在也能修改，留空的位置可接受其他原生可选技能，不再只适合法系。

升级时优先使用已有的基础职业档案。缺少基础档案时优先从原来正在编辑的同系进阶档案建立，其次使用旧配置中的第一份同系进阶档案。旧进阶档案仍可通过 JSON 导出查看。魔法师可继承旧版共用备份，其他无历史档案的职业默认前三技和宝箱优先级留空。

手动切换编辑档案会暂停助手，避免用其他职业的配置自动选牌；再次启动时载入当前角色的基础职业。全部职业档案随 JSON 一起导出／导入。避怪、拾取、自动2x、重复远征、定时退图、结算穿装及出售仍是全局设置。

## 树精卡循环：3 分钟后收尾、结算、重进

在“自动远征／新周目开荒”中点击 **“套用树精卡循环：一周目斐扬森林／3分钟”**，然后启动助手，即可设置：一周目斐扬森林、固定地图重复远征、局内 3 分钟开始收尾、最多再拾取 20 局内秒、自动拾取开启。原有技能／宝箱优先级、难度、开局上限及结算穿装／出售设置继续生效。

也可手动勾选“到时收尾拾取并结束结算”，自选地图、周目、分钟数和收尾时限；仅作用于该地图及周目。需要重复时同时勾选自动远征，定时循环与首通开荒互斥。两项计时都按游戏内时间：3 分钟在正常 2x 下约为现实 90 秒，选牌、掉落确认和游戏暂停不计入局内时间。

收尾优先拾取卡片，再处理开始收尾时地面已有的装备／宠物蛋，收尾中新增卡片也会关注；不主动寻宝箱或追新装备。仍使用正常移动、寻路、避怪及拾取范围，已打开的掉落确认会完成后再退图。没有待收物品会提前结束，达到收尾时限则停止寻找；**未实际拾取的地面物品不会入账**。

游戏的普通“退出”会保存断点，因此这里调用原生“结束结算”流程，保留已拾取的卡片、装备和经验，清除该局断点；中途结束按未获胜处理，不额外增加通关或 MVP 奖励。之后沿用原有结算整理及队长出发流程，开始全新一局，不继续上次的 3 分钟进度。找不到原生结束按钮或结算未完成时停下提示，不改用保存退出，也不重复结算。

组队、剧情、PVP、无限之塔、录像和已离开副本的页面不执行定时退图。暂停助手或手动操作时仍优先让出控制，开启后按本局进度继续。建议先用较小的自动开局上限确认自己的角色、拾取范围和收尾时限；目前尚无真实账号实战验证。

## 进入单人远征自动 2 倍速

新增“进入单人远征自动2倍速”勾选，默认关闭。勾选并启动助手后，进入每一局单人远征时自动点击游戏计时器旁的原生“1x／2x”按钮，包含六周目、圣诞节及元宵节。局中勾选也会应用一次，设置随配置保存及导入／导出。

每局只设置一次；已经是 2x 时不会再点。会等待本局原生按钮初始化，避免把上一局残留的 2x 当作设置成功。手动改回 1x、或原生检测到卡顿自动降速时，助手保持当前速度；下一局重新应用。取消勾选不会把当前速度切回 1x，若需要重新自动设为 2x，可在本局重新勾选。

组队、剧情、PVP／公会战、录像以及无限之塔不使用此开关；无限之塔原有的 x2／x4 保持原样。原生不提供按钮或按钮无法生效时显示等待／提示，其他助手功能照常运行。仅使用游戏原生切换和速度计数，不改写游戏时钟、移动速度或运行登记。

## 斐扬洞穴・改：月夜猫钟罩避难

新增“钟罩倒数自动进罩”，默认开启，需同时开启“自动避怪”。识别月夜猫实际生成的钟罩和位置，倒计时期间优先按地图寻路进罩，暂停寻宝、拾取和掉落确认；进罩后在安全边界内继续避怪，钟声发出后暂留罩内，机制结束再恢复原有流程。

当前原生机制中，普通钟倒计时 9 秒；封印钟倒计时 23 秒，需先在 20 秒内击杀九尾狐解除封印。**封印未解除时，走进钟罩仍会受伤**。助手会显示封印提示并靠近钟罩，但不保证自动击杀九尾狐；请关注输出和解除封印状态。

安全判断读取原生钟罩半径，并额外留出边界余量，不修改伤害或角色移动速度。寻路不可达时停止自动移动并提示手动处理。手动操作、暂停助手、关闭自动避怪或本勾选仍可接管；选牌时先完成原有选牌流程。后台模式开启时同样执行进罩，但浏览器冻结标签页或电脑休眠仍会中断运行。诊断中可查看钟罩位置、半径、封印和发动状态。

## 独立重抽开关

面板的“重抽設定”中有两个可独立保存的勾选项：

- **局內技能：允許重抽**：仅在没有符合技能配置的选项时重抽整组；取消勾选后，有合规牌照常选择，无合规牌等待手动选择。
- **寶箱：允許重抽**：控制宝箱单张和整组重抽；取消勾选后，按已有优先级和“重抽用盡／達上限後”设置选择现有卡片或等待手动选择。

两个开关默认开启，以延续 v1.3.0 行为。旧配置中的技能开关、宝箱策略（含“不重抽”）、重抽上限和保留次数继续生效。勾选宝箱重抽后，仍需策略允许且有剩余次数才会重抽；开关不保证一定重抽。每次修改立即保存，可导入／导出 JSON。使用同一游戏域名的原有浏览器配置和面板位置会保留。

## 宝箱并列优先级

每个栏位的“加入哪个优先级”下拉框可选择已有级别或“新增优先级”，再从物品表选入物品。连续加入同一级时自动并列，重复物品不会再添加；同名但 ID 不同的物品可以分别加入。

例如，先把冷却药水、生命药水加入第 1 级，再把伤害药水、范围药水加入第 2 级，保存结果为：

```text
冷卻藥水 [p_cd] | 生命藥水 [p_hp]
傷害藥水 [p_dmg] | 範圍藥水 [p_area]
```

同一行的所有物品都并列，行与行之间才有先后。任一第 1 级物品命中均视为首选，后续仍按成型、累计等级、均衡和稀有度比较。也可直接编辑文本，用 `|` 或 `｜` 分隔同级项目；旧的单项、多项和纯 ID 配置均兼容。

## 宝箱智能追首选、补齐与均衡

“智能追首选”默认开启，旧配置自动兼容，优先级内容、重抽上限、保留次数和用尽后的处理方式不变。

选牌顺序为 **配置优先级 → 同级补空／成型需求 → 保留已有物品累计等级 → 均衡等级 → 稀有度**。空栏第二优先级不会压过已占栏的第一优先级。同级先补空栏，再将可替换的非首选神格换成首选，最后升级已有首选；同等需求时避免换掉已有累计等级的物品。

智能追首选和补齐开关同时开启时，根据**已填栏位数量**分阶段，先填任意两栏，不限定种类；面板会显示已填数量和当前策略：

- **已填 0／1 栏**：没有首选牌时，优先用整组重抽快速选定前两栏，即使牌面已有需要的类型，也先整组追首选。整组次数不足、被保留或模式不允许时，改用可用单张。
- **已填 2／3／4 栏**：其余栏位优先单张追首选；需要的类型没有出现，或没有可用单张时，继续使用剩余整组次数补齐。整组不会因为前两栏选完就停用。
- **单张重抽保持类型**：药水仍是药水；整组重新随机类型，但不保证每次都能换出需要的类型。
- **保护已出现的首选**：不重抽首选牌、不整组重抽丢掉首选；只有其他牌能抽到更需要的首选时，才继续单抽。没有这种机会就直接选择首选，不为稀有度或小幅等级差继续消耗。
- **过滤不可达目标**：普通物品填进栏位后通常锁定种类，单张或整组均无法换成另一种普通物品；神格结合已学技能、替换次数与放逐状态判断。助手只读取原生可抽池，不试抽、不推进随机数。仅在开启“选后放逐”且满足其条件时自动点击宝箱神格放逐；不主动使用 Focus。

“仅单张／仅整组／不重抽”、宝箱重抽总开关、每箱上限和保留次数始终有效。关闭智能模式后，按原先单张／整组顺序执行并遇首选即选。同优先级补齐／均衡开关关闭时，不启用两阶段补齐策略，也不为补齐或均衡追加重抽。无法确定已填数量时，沿用按可达类型选择重抽的策略。

未命中首选且无法继续重抽时，仍按现有“选最优项／等待手动”设置处理。“选最优项”允许次优填空栏，这可能锁定该栏本局物品种类；选择“等待手动”则停下。未配置优先级时不重抽。

助手读取游戏 `runItems.slots`，无法获取时再读取 HUD；不凭卡片的“新”标记猜测栏位是否已有物品。无法确认可抽池时，不在保住首选后追加重抽。每箱重抽分别计数，重绘卡牌不清零，连续开下一箱会清零。日志显示目标类型及决策原因。五栏全部填满不等于物品已达到最高等级。

## 按角色等级／宝箱五栏总等级立即升级或保存

在“新版技能／宝箱保存与开启”中提供两项独立勾选，默认关闭，随职业保存：

- **技能按局内角色等级**：例如填100，角色低于100级时立即选择技能，达到100级后保存技能升级机会；这里读本局角色等级，和技能等级之和不同。
- **宝箱按五栏总等级**：例如填50，五栏总等级低于50时立即开箱选牌，达到50后保存宝箱。初次取得的一张算1级，界面“+N”对应N+1级；空栏0级，五栏相加，不额外计入技能或普攻。

规则启用后接管该类的原生保存开关，未达标会关闭保存并自动拿出该类已保存牌，达到阈值后开启保存并保留当前尚未选的牌。每次选择后重新读取等级，达到阈值就停，不把整批剩余宝箱选完。两项互不影响，在助手启动且对应类型开启自动选牌时生效。启用等级规则的类型优先按其阈值决定是否自动开启。

手动开启、B键和原生分页面板可以接管当前批次；手动“继续保存”会暂缓自动取出及等级策略，按开启或调整规则可恢复。暂停助手、界面加载、等级无法确认及非支持模式时不会猜测等级或丢弃机会。读取不到保存控件时保留需要保存的牌面并提示等待。

旧“按时间／技能总等级保存（原不再翻牌）”整块设置及运行逻辑已删除。旧阈值不再生效，也不强行换算成角色等级；原技能、宝箱优先级、重抽、神格及职业配置保留。面板显示本局角色等级、五栏总等级、技能待选数和宝箱待选数。

## 三系技能升级顺序

火箭术、冰箭术、雷击术的“增加目标数”升级固定先于稀有度。例如普通 `+1 目标` 会排在传说伤害升级之前；同为这三系的目标数升级时，再比较稀有度。

“其余技能牌先比稀有度”开关继续控制其他卡牌的排序，不会覆盖三系目标数升级的优先规则。此规则针对已有技能的升级牌，不把新技能介绍中出现的“目标”当成这类优先升级。

## 结算后穿装和出售

两个功能均默认关闭，可分别勾选，不依赖重复远征开关；执行顺序是返回广场、穿装、出售、下一场。

- 自动穿装使用原生“一键穿装”，选择能穿且装备分数更高的装备，武器保持同类型；原装备插卡不会自动转移。
- 自动出售需同时勾选总开关和品质。普通、优良、稀有、史诗、传说分别控制，默认都不选；“优良”是游戏额外提供的品质。
- 出售复用矿石商人的原生“一键贩卖”和确认流程，处理背包中所有符合所选品质的可售装备。任何角色穿戴中、受保护、初始、角色专属、插卡和精炼装备均保留，卡片不出售。
- 同时启用时，先换上的更优装备会被原生出售规则保护。确认前改变出售设置会取消该次出售；保存失败或结果未确认时停止下一次远征，并显示商人提示。

整理时通过原有方向键走到矿石商人，整理完再回远征队长。手动方向键或点击移动会优先让出操作；暂停助手会释放自动按键。
